# 📂 LeetCode Solutions

A structured collection of my LeetCode solutions written in **JavaScript**. 
Focused on building problem-solving skills for software engineering roles in the **Ireland tech market** 

---

## 🗂️ Folder Structure

```
leetcode-solutions/
├── arrays/
├── hashmaps/
├── sliding-window/
├── two-pointers/
├── stack/
├── binary-search/
├── linked-list/
├── trees/
├── heap/
└── dynamic-programming/
```

Each file follows the naming convention: `{problem-number}-{problem-name}.js`  
Example: `001-two-sum.js`, `121-best-time-to-buy-sell-stock.js`

---

## 📝 File Template

Every solution file includes:

```js
/**
 * {problem number} - {problem name}
 * Difficulty: Easy | Medium | Hard
 * Link: https://leetcode.com/problems/{slug}/
 * Pattern: e.g. Hash Map, Two Pointers, Sliding Window
 *
 * Approach: one-line description of the strategy
 * Time:  O(?)
 * Space: O(?)
 */

// solution code here
```
